# Retail-Sales-Analysis-SQL

## Project Overview
This project analyzes retail sales data using SQL. It covers data exploration, sales analysis, customer analysis, product analysis, and advanced SQL concepts. The project demonstrates SQL skills from beginner to advanced level using a retail sales dataset.

## Database
**Database Name:** `product_order`

## Dataset
- Orders
- Product Supplier
- Dataset Size: **10,000+ records**

## Tools Used
- MySQL Workbench
- SQL

## Skills Demonstrated
- Data Exploration
- Filtering & Sorting
- Aggregate Functions
- GROUP BY & HAVING
- Joins
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- Date Functions
- Sales & Customer Analysis

## Project Highlights
- Analyzed **10,000+ retail sales records**
- Wrote **70+ SQL queries**
- Covered beginner to advanced SQL concepts
- Performed sales, product, supplier, and customer analysis
- Identified monthly sales trends and business insights

## Files
- `Retail_Sales_Analysis.sql`
- `orders.csv`
- `product_supplier.csv`

## How to Run
1. Create a database named `product_order`.
2. Import the `orders.csv` and `product_supplier.csv` datasets.
3. Open `Retail_Sales_Analysis.sql` in MySQL Workbench.
4. Execute the SQL queries to reproduce the analysis.
